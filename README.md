A developer portfolio website for **Katta Mahima Vara Kumari**, Computer Science undergraduate at **IIIT Pune** (2024–2028), specializing in backend engineering, API systems, and practical AI/ML applications.

- **Hero Section**: Editorial design with interactive system manifest code architecture element and direct recruiter links.

- **Skills**: Clean categorized grid (Languages, Backend & APIs, Frontend, Databases, AI/ML, Tools) without fake percentage bars.
- **Experience**: CDAC Noida Ethical Hacking & Penetration Testing Intern timeline.
- **Honors & Certifications**: Claude 101, Infosys Responsive Web Design, Rajya Puraskar Governor's Award, Inter-IIIT Volleyball.
