A full-stack API monitoring platform featuring scheduled endpoint health checks, failure detection, and incident management.

**Highlights:**

- JWT-based authentication.
- Request validation using Zod.

**Highlights:**

- Data processing with Pandas and NumPy.
- Interactive risk prediction demonstration.

[GitHub Repository](https://github.com/KattaMahimaVaraKumari/Cognivault)

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/KattaMahimaVaraKumari/Portfolio.git
```

Navigate to the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📦 Production Build

```bash
npm run build
npm run preview
```
