## 🚀 Featured Projects

### 1. Monitorly – API Monitoring & Incident Management

A full-stack API monitoring platform that performs scheduled health checks, detects endpoint failures, and manages incidents.

- Backend built with Node.js and Express.js.
- MongoDB for data storage.
- JWT-based authentication.
- Scheduled monitoring using node-cron.
- Request validation using Zod.

[GitHub Repository](https://github.com/KattaMahimaVaraKumari/api-monitoring-system) · [Live Demo](https://api-monitoring-sy-git-6fd773-katta-mahima-vara-kumaris-projects.vercel.app/)

### 2. Cognivault – Student Burnout Risk Prediction

An explainable machine learning project that predicts student burnout risk across four categories: Low, Moderate, High, and Critical.

- Machine learning using Scikit-learn.
- Data processing with Pandas and NumPy.
- Explainable predictions and risk insights.

[GitHub Repository](https://github.com/KattaMahimaVaraKumari/Cognivault)

### 3. DocAppointix – AI-Enabled Healthcare Platform

A healthcare platform connecting patients and doctors through appointment management and AI-assisted features.

- MERN stack architecture.
- AI-powered symptom analysis using Google Gemini.
- Real-time video consultations.
- Digital prescriptions and recovery tracking.
- Integrated payment functionality.

[GitHub Repository](https://github.com/KattaMahimaVaraKumari/DocAppointix) · [Live Demo](https://docappointix-frontend.onrender.com/)

## 💻 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the project directory

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 📦 Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
